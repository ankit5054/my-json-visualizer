JSON Viewer

A free, browser-based tool to explore, format, and debug JSON — no install, no dependencies, no data leaves your browser.

  • 🎨 Formatted view — syntax-highlighted, pretty-printed JSON
  • 📊 Table view — explore arrays as rows with column headers
  • 🌲 Tree view — collapsible node-by-node structure
  • 🔍 Drill down — click into nested objects and arrays
  • 🧭 Breadcrumb path — trace and jump back through nested levels
  • 🔎 Filter & search — filter table rows by key, value, or condition
  • 🛠 Auto-fix — repairs trailing commas, unquoted keys, and Python-style values
  • 📋 Copy — copy formatted JSON to clipboard instantly
